

# Problem A - The Secret Vault

## Problem Description

Deep inside an ancient underground laboratory lies a mysterious vault containing priceless treasures. The vault is protected by a special security system.

You may enter password codes one by one.

The vault will unlock if **either** of the following conditions is satisfied:

* The password is divisible by **7**, or
* The password is exactly **777**.

If the password is incorrect, the security system rejects it and waits for another attempt.

Write a program that keeps reading password codes until the vault is successfully unlocked.

---

## Input

The input consists of several integers, one per line.

It is guaranteed that at least one password will eventually unlock the vault.

---

## Output

For every incorrect password, output

```text
Access Denied
```

When a correct password is entered, output

```text
Access Granted
```

and terminate the program immediately.

---

## Sample Input 1

```text
10
20
25
777
```

## Sample Output 1

```text
Access Denied
Access Denied
Access Denied
Access Granted
```

---

## Sample Input 2

```text
5
8
21
```

## Sample Output 2

```text
Access Denied
Access Denied
Access Granted
```

---

## Constraints

```text
-10^9 ≤ password ≤ 10^9
```

It is guaranteed that at least one password satisfies the unlocking condition.

---

## Hint

Continue reading passwords until one of them

* is divisible by **7**, or
* is exactly **777**.
