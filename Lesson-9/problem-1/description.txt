## Problem: Integer to Roman Numeral

### Description

Roman numerals are represented by seven different symbols:

| Symbol | Value |
| ------ | ----: |
| I      |     1 |
| V      |     5 |
| X      |    10 |
| L      |    50 |
| C      |   100 |
| D      |   500 |
| M      |  1000 |

Roman numerals are formed by converting each decimal place from highest to lowest.

The following rules are used when converting an integer into a Roman numeral:

1. If the current value does not begin with **4** or **9**, choose the largest Roman numeral value that is less than or equal to the current value. Append its symbol to the result and subtract its value. Repeat this process until the value becomes 0.

2. If the value begins with **4** or **9**, use the subtractive notation.

   The following subtractive forms are allowed:

   | Value | Roman Numeral |
   | ----: | ------------- |
   |     4 | IV            |
   |     9 | IX            |
   |    40 | XL            |
   |    90 | XC            |
   |   400 | CD            |
   |   900 | CM            |

3. The symbols **I**, **X**, **C**, and **M** can appear consecutively at most three times.

4. The symbols **V**, **L**, and **D** cannot appear consecutively.

Given an integer, convert it into its corresponding Roman numeral.

### Input

The input contains one integer `n`.

### Output

Output the Roman numeral representation of `n`.

### Constraints

```text
1 ≤ n ≤ 3999
```

### Example

**Input**

```text
1994
```

**Output**

```text
MCMXCIV
```
