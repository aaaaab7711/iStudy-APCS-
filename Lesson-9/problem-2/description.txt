# Problem: Roman Numeral to Integer

## Description

Roman numerals are represented by seven different symbols:

| Symbol | Value |
| ------ | ----: |
| I      |     1 |
| V      |     5 |
| X      |    10 |
| L      |    50 |
| C      |   100 |
| D      |   500 |
| M      |  1000 |

Roman numerals are usually written from largest to smallest from left to right.

For example:

* `II = 2`
* `XII = 12`
* `XXVII = 27`

However, in some cases, a smaller value is placed before a larger value to indicate subtraction.

There are six possible subtractive combinations:

| Roman Numeral | Value |
| ------------- | ----: |
| IV            |     4 |
| IX            |     9 |
| XL            |    40 |
| XC            |    90 |
| CD            |   400 |
| CM            |   900 |

Given a valid Roman numeral, convert it into its corresponding integer.

---

## Input

The input contains a string `s`, representing a valid Roman numeral.

---

## Output

Output the integer value represented by `s`.

---

## Constraints

```text
1 <= s.length <= 15
```

* `s` contains only the characters `I`, `V`, `X`, `L`, `C`, `D`, and `M`.
* It is guaranteed that `s` is a valid Roman numeral.
* The value of `s` is between `1` and `3999`.

# C++ Reference Solution

```cpp
#include <iostream>
#include <string>
#include <unordered_map>
using namespace std;

int main() {
    string s;
    cin >> s;

    unordered_map<char, int> value = {
        {'I', 1},
        {'V', 5},
        {'X', 10},
        {'L', 50},
        {'C', 100},
        {'D', 500},
        {'M', 1000}
    };

    int result = 0;

    for (int i = 0; i < s.length(); i++) {
        // If the current symbol is smaller than the next symbol,
        // subtract it.
        if (i < s.length() - 1 && value[s[i]] < value[s[i + 1]]) {
            result -= value[s[i]];
        } else {
            result += value[s[i]];
        }
    }

    cout << result << endl;

    return 0;
}
```

## 解題概念

判斷目前的羅馬數字和下一個數字：

* 如果 **目前數值 < 下一個數值** → 代表是減法，例如 `IV`
* 否則 → 直接加到答案中

例如：

```text
MCMXCIV
```

計算過程：

```text
M  = +1000
C  < M  → -100
M  = +1000
X  < C  → -10
C  = +100
I  < V  → -1
V  = +5
----------------
Total = 1994
```
